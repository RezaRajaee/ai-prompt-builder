# 🎬 AI Video Prompt Builder

**A lightweight desktop GUI that builds structured, high-conversion prompts for AI video generators — in seconds, with zero typing.**

Built for creators using **Google Veo, Kling, Runway Gen-3, Pika, Hailuo, and PixVerse.** Pick from 20+ fine-tuned dropdown menus — camera angle, lighting, mood, style, character, environment — and get a clean, ready-to-paste prompt instantly.

## ✨ Why this tool

- **No more blank-page prompt writing.** Every field is a dropdown — no guessing what keywords AI video engines respond to.
- **20+ fine-tuning parameters**: camera motion, shot angle, lighting, character look, wardrobe, environment, time of day, VFX, color grading, and negative prompts.
- **Persian (RTL) interface, English prompt output** — built for Persian-speaking creators who publish to global platforms.
- **Zero dependencies.** Pure Python standard library — no bloated installs.
- **One-click copy** straight to your clipboard, plus save/load your prompt sessions as `.txt`.

## 🚀 Getting Started

### Option A — Run from source (any OS)
```bash
git clone https://github.com/RezaRajaee/ai-prompt-builder.git
cd ai-prompt-builder
python prompt_builder.py
```
Requires Python 3.8+. No extra packages needed.

### Option B — Windows .exe (no Python required)
Download the latest `.exe` from the [Releases](../../releases) page and double-click to run.

*(Building it yourself: run `build_windows.bat` on a Windows machine with Python installed — it packages the app into a single standalone `.exe` via PyInstaller.)*

## ⌨️ Shortcuts

|    Action   | Shortcut |
|-------------|----------|
| New prompt  | `Ctrl+N` |
| Save prompt | `Ctrl+S` |
| Copy output | `Ctrl+C` |
