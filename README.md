# 🎬 AI Video Prompt Builder (GUI)

An interactive, lightweight, desktop GUI tool developed in Python (`tkinter`) designed to construct structured, high-conversion video generation prompts for modern generative video AI engines (such as Google Veo, Kling, Runway Gen-3, Pika, Hailuo, and PixVerse).

---

## ✨ Features

- **Intuitive Dual-Column Layout**: Clean, responsive layout with dynamic canvas scrolling.
- **RTL Support**: Optimized Persian UI alignment paired with English output prompt generation.
- **20+ Fine-Tuning Parameters**: Detailed control over camera motion, shot angle, lighting, styles, characters, rendering quality, and negative prompts.
- **Robust Clipboard & File Handlers**: Multi-engine clipboard copy mechanism (with fallback) and native `.txt` project export.
- **Keyboard Shortcuts**: Standard bindings (`Ctrl+N`, `Ctrl+S`, `Ctrl+C`).
- **Zero External Dependencies**: Runs instantly on pure standard Python.
